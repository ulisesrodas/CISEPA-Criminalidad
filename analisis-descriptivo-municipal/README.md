# Sesion 3: analisis descriptivo municipal

Esta carpeta contiene todos los archivos necesarios para trabajar la sesion 3. Los nombres fueron simplificados para evitar problemas al descargar materiales desde Paideia.

Esta version incluye una seccion ampliada de visualizaciones con `ggplot2`, `plotly`, `patchwork`, `hrbrthemes`, `paletteer`, `ggridges` y `ggbeeswarm`.

## Como usar

1. Descargar todos los archivos de esta carpeta.
2. Abrir `sesion3_analisis_descriptivo_municipal.qmd` en RStudio.
3. Ejecutar primero los bloques:
   - Instalar paquetes
   - Activar paquetes
   - Ubicar archivos
4. Luego ejecutar el resto del documento por secciones o usar `Render`.

## Archivos principales

- `sesion3_analisis_descriptivo_municipal.qmd`: documento principal.
- `renamu2025.csv`: base RENAMU 2025.
- `dict_renamu2025.pdf`: diccionario de variables de RENAMU 2025.
