# Análisis de Conglomerados: Criminalidad y Seguridad Ciudadana

Este directorio contiene el desarrollo y los resultados del **Análisis de Conglomerados (Cluster Analysis)** aplicado a datos de criminalidad. El objetivo principal de este análisis es identificar y agrupar perfiles o casos con características similares, permitiendo entender mejor los patrones de seguridad ciudadana a través de métodos cuantitativos.

---

## 📂 Contenido del Directorio

El análisis ha sido documentado y exportado en dos formatos para facilitar su lectura y revisión:

* **`analisis-de-conglomerados.pdf`**: Documento estático, ideal para lectura lineal, impresión o revisión académica.
* **`analisis de conglomerados.html`**: Versión interactiva que permite visualizar mejor las tablas, gráficos.
* **`analisis de conglomerados.qmd`**: Archivo Quarto que analiza el archivo `pope.csv` aplicando algoritmos de clustering (K-means, jerárquico, DBSCAN y PAM) para encontrar diversos perfiles penitenciarios.

---

## 🛠️ Herramientas y Metodología

Para este proyecto se aplicaron técnicas de aprendizaje no supervisado y estadística descriptiva avanzada, utilizando el siguiente stack analítico:

* **Lenguaje y Entorno:** R / Quarto.
* **Manipulación de Datos:** `tidyverse` (y librerías asociadas para limpieza y transformación).
* **Modelamiento:** Algoritmos de agrupamiento (como *K-means* o clustering jerárquico) para segmentar las observaciones en clústeres significativos.
* **Visualización:** Gráficos multivariados para la interpretación de los grupos formados.

---

## 🚀 Cómo visualizar el reporte HTML

1. Descarga o clona este repositorio en tu equipo local.
2. Navega hasta la carpeta `analisis-conglomerados`.
3. Haz doble clic en el archivo `analisis de conglomerados.html` para que se abra automáticamente en tu navegador web predeterminado (Chrome, Firefox, Edge, etc.).
